# SBP-26-27
Repo de les pràctiques de SBP del grau EET

### FUNCIONAMENT DEL REPO
#### *Únicament es modificarà el codi i es debuguejarà aquí, qualsevol altra cosa que no sigui codi s'ha de fer desde local*
El funcionament és senzill:
- Crear una carpeta per cada pràctica
- Afegir una copia del arxiu del CCS la qual serà la que s'anirà modificant per tal de si en algun cas alguna cosa anés malament, es podria tornar a tenir l'arxiu inicial.
- Un cop comprovat el funcionament (debug etc), es podrà copiar l'arxiu **de codi (.c)** a la carpeta personal on hi ha el projecte per tal
- Push
- **Git PULL** i s'obre l'arxiu **.c** i es copia el codi i es posa dins el projecte *personal* que tenim obert de les pràctiques
